# 智医通项目

## 项目概述

智医通是一个基于人工智能的症状自查小程序，旨在提高基层医疗机构的问诊效率和准确率。本项目基于Llama-3模型进行轻量化微调，实现常见病症状识别与初步分诊建议。用户输入体征数据后，系统通过结构化问诊流程生成风险评估报告，提供就诊科室推荐。

## 系统架构

本项目采用前后端分离的架构设计，包括以下组件：

### 前端（Frontend）
- 用户端：症状自查、健康档案、就医指南
- 医生端：患者管理、问诊辅助、数据分析
- 管理端：系统监控、数据管理、用户管理

### 后端（Backend）
- API服务：RESTful API接口
- AI模型服务：症状识别、问诊路径生成、风险评估
- 数据处理服务：数据清洗、特征提取、模型训练

### 数据库（Database）
- 用户数据库：用户信息、健康档案
- 医疗知识库：症状库、疾病库、药品库
- 模型数据库：训练数据、模型参数

## 技术栈

### 前端技术
- 框架：React.js + Vite
- UI组件库：Ant Design
- 状态管理：Redux
- 路由：React Router

### 后端技术
- 框架：Flask (Python)
- API文档：Swagger
- 身份认证：JWT

### 数据库
- 关系型数据库：MySQL
- 非关系型数据库：MongoDB（存储非结构化医疗数据）

### AI模型
- 基础模型：Llama-3-8B
- 模型优化：知识蒸馏、量化、剪枝
- 部署方案：ONNX Runtime

## 核心功能

1. **症状描述解析**：通过自然语言处理技术解析用户描述的症状
2. **结构化问诊流程**：基于状态机模型的交互式问诊
3. **风险评估**：基于贝叶斯网络的疾病概率计算
4. **分诊建议**：推荐就诊科室和就医级别

## 项目特色

- 轻量化AI模型，适配移动端运行
- 个性化问诊路径，提高问诊效率
- 双输入模式（症状关键词+体征数据），降低使用门槛
- 专注基层医疗场景，支持医患双向使用
